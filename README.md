Exercício Node.js

Repositório criado para a realização de um exercício prático em sala de aula, com o objetivo de aprender a iniciar um projeto utilizando Node.js, NPM e GitHub.

Passo a passo da criação:

1:Criar uma pasta localmente no computador.
2:Nomear a pasta como exercicio-node-nome.
3:Abrir a pasta no Visual Studio Code.
4:Abrir o terminal e executar o comando:
npm init -y
5:Editar o arquivo package.json, preenchendo as informações description e author.
6:Inicializar o Git e realizar o primeiro commit.
7:Criar um repositório público no GitHub.
8:Criar o arquivo README.md para documentar o projeto.
9:Enviar os arquivos para o GitHub.
